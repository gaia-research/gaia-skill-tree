# Codebase Graph Retrieval

## Description

Indexes a source repository into a graph of prose code nodes and call/reference edges, then retrieves the relevant nodes with exact file:line spans into an agent's context so it can locate code, trace callers, and scope an edit's blast radius without reading raw source.
