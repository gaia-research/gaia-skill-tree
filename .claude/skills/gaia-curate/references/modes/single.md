# Single mode

Use for one manually selected public source page. Freeze a ceiling of five
candidates and process exactly one active candidate at a time.

For each listing, resolve and actually fetch the upstream `SKILL.md`; a listing
page or repository root is not the artifact. Preserve the canonical URL,
retrieval time, source lane, repository, cited origin, available commit SHA,
content SHA-256, and non-empty `name` and `description` frontmatter. Source
popularity may prioritize inspection but is not trust or evidence.

Persist the complete generic snapshot before the first candidate. Finish and
validate one packet before advancing. After no more than five candidates, write
the L4 presentation and stop at the shared boundary in `CURATION-CORE.md`.
