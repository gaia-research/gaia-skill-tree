Getting startedabout 10 minutes

Install, scan, and propose your first skill

Install the CLI, initialise your profile, scan a repository, and propose what you hold to canon. Rank comes later, from review.

Prerequisites

  • Python 3.10 or newer
  • pip, or pipx for an isolated install
  • A Git repository: gaia scan and gaia push need one

Working outside a public repository? Workspace Mode scans and tracks skills locally without remote pushes.

Install

The install script prefers pipx and falls back to pip install --user, printing a PATH hint if it needs one.

shell
curl -fsSL https://gaiaskilltree.com/install.sh | sh

Install from source

shell
git clone https://github.com/gaia-research/gaia-skill-tree.gitcd gaia-skill-treepython -m venv .venv && source .venv/bin/activatepip install -e ".[dev,embeddings]"

If the gaia command is blocked in your environment, run it as a module: python -m gaia_cli <command>.

Initialise your profile

shell
cd my-agent-repogaia init --user <your-github-handle>

Your handle is the name that appears in Honor Red beside every named skill you hold. Use your real GitHub username; it stays on the record.

Scan your repository

gaia scan reads SKILL.md files and the agent skill folders in your repository, maps them to capabilities in the registry, and lists the fusions you are close to.

shell
gaia scan# Scanning repo: my-agent-repo# 3 skills detected · 1 fusion one prerequisite away

Propose to canon

gaia push proposes your structure for review. It never sets a rank: rank is assigned by canon after topology and evidence review, and every change lands on the skill's timeline.
