## Verified looks right

- **Hero (desktop + mobile):** monochrome tonal-gold World Tree silhouette reads as one atmosphere; `Gaia` in solid text + `Skill Tree` in Apex Gold EB Garamond, no gradient text; copy fully legible over the tree; install card, "Submit a skill" / "Get a README badge" affordances, and the SKILLS/NAMED/ULTIMATES stat strip all clean and aligned. Mobile is the correct full-bleed backdrop with copy anchored to the lower third — not a boxed top band.
- **Nav chrome:** plain 1px hairline over `--bg`, no frosted glass; Diamond Seal `◇G` + wordmark left, links right — structure matches the retired-glass spec (color caveat noted above).
- **Hall of Heroes band:** ceremonial two-column ledger — left `Registry honors` / oversized EB Garamond title / ledger pills / three Hall links; right generated plaque rail. Avatars framed by GOLD wreaths, contributor handles in Honor Red, no RED origin mark inside any wreath. Secondary skill rows in violet star bars = correct 3★/4★ rank color, not a defect.
- **Evidence Grade band:** Platinum/Gold/Silver/Bronze/Ungraded ladder bars are aligned, labeled, and readable; supporting copy and the four action buttons sit clean.
- **Meta Reports band:** three report cards with red category eyebrows, EB Garamond titles, italic summaries, consistent arrows; "Open Meta Changelog" + "Open All Reports" well placed.
- **Footer:** four link columns (Registry / Discover / Evidence / Docs) + Contribute/About, Gaia Research call-out, and bottom legal strip all aligned; `@mbtiongson1` correctly in Honor Red; no overflow.
- **No horizontal overflow at 390px** (scrollWidth == innerWidth == 390 on every section) and **no broken visible images** in either viewport. Console 404s are all `/api/v1/skills/**.json` data fetches (graceful-degrade, not visual) plus a `localhost:8400/live.js` dev-only script — none produce a visible defect.
