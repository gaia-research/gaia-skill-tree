# Scout D — Outer public pages design-intent review (2026-07-20)

Surfaces: Priority 1 — `/about.html`, `/meta.html`, `/codex.html`, `/codex/trust-methodology.html`, `/starless.html`. Priority 2 — `/api/`, `/benchmarks/`, `/evidence/`, `/trending/`, `/trust/` + `/trust/ledger/`.
Viewports: 1280x900 (desktop) and 390x844 (mobile). Playwright 1.61.1 against `http://localhost:8090/`.
Screenshots (not committed): scoutA/ — `outer-*` full-page, `scr-*` scrolled section shots.

Lens: designer's eye — layout/overlap/hierarchy/color-in-context/readability/empty-broken states. Token-vs-hex bookkeeping out of scope. Watching for dead `--tier-extra`(purple)/`--tier-ultimate`(amber) symptoms (accents rendering cyan/unstyled), rank-vocab defects (4★ reading "Extra"), and red origin marks (should be gold).

Global: **no horizontal overflow at 390px on any page** (scrollWidth == innerWidth everywhere). Nav renders at ~60px with correct fixed-nav clearance on every page **except `/api/`** (see finding). `/trust/` and `/codex/trust-methodology.html` serve identical content (same doc). Only console noise is one `net::ERR_CONNECTION_REFUSED` (dev `localhost:8400/live.js` reload script) plus a few `/api/**.json` 404 data fetches — none produce a visible defect except where noted.

## Verified looks right

- **/about.html:** clean atlas-plate layout — Marcus B. Tiongson crest, "A registry, not a marketplace" stat strip (6 ultimates in gold), forkable-schema cards, contributor tool cards with correct rank badges (`@garrytan` 5★ gold, `@mattpocock` 6★ gold, `@pbakaus` 4★ violet), red contributor handles, and a clean vertical career timeline. Mobile stacks cleanly. (One quote-glyph nit above.)
- **/meta.html:** "Meta Reports" — two-column report card grid, red category eyebrows, EB Garamond titles, consistent share/download/link controls, "Meta Timeline" CTA; nav clearance correct, footer aligned.
- **/codex.html:** "The Codex" — Curate Chain L1–L5 pipeline diagram, terminal empty-state ("Click Run Simulation…"), What-Automation-Does / Reviewer-Path columns, and the Branch Naming Convention table all read cleanly and are well aligned.
- **/codex/trust-methodology.html (= /trust/):** long reference doc — hero, TOC "On this page", and the many evidence/threshold tables are organized and legible; nav clearance correct.
- **/starless.html:** "Starless" rank-less taxonomy — alphabetized two-column list, contributor handles correctly in Honor Red, redacted sub-2★ handles rendered as intentional grey blocks, "no named skills yet" empty rows read as deliberate; A–F right-edge jump index present. No red origin-mark misuse.
- **/benchmarks/:** "How do we know a skill is real?" hero (gold "is real?" emphasis, consistent with the homepage lock-up), HumanEval/MMLU provenance cards, Gaia Skill Bench weighting list (40/30/20/10), "IN DESIGN" state disclosed inline with a "Follow issue #960" link; nav + footer present.
- **/evidence/:** "Evidence Library" — stat tiles (626 / 306 / 116 / 65) and the Bronze/Silver/Gold/Platinum/Ungraded grade-distribution panel are aligned and readable; search + evidence-type/grade filter rows clean. Very long (626 rows) but that is expected.
- **/trending/:** "Trending Skills" ranked list, "Recently Awarded" rank-up cards, and "Most Consumed" rows all readable; rank/grade/NEW pills legible (gold-border note above).
- **/trust/ledger/:** dense sortable ledger is well-structured — sticky header, grade badges (S blue / A gold), MAG deltas with red ▼ markers, per-month rank columns all aligned (rank-color inversion note above is the only issue).
