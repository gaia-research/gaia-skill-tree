Surfaces: `/heroes/` (Hall of Heroes gallery + share modal), Profiles (`/u/mattpocock/`, `/u/obra/`), `/reports/` index + `/reports/2026-28/` detail + `/named/report.html`.
Method: Playwright 1.61.1, viewports 1280×900 and 390×844. Screenshots in `scratchpad/scoutC/`. Visual judgment + `getBoundingClientRect` for overlaps, horizontal-overflow + console-error checks per page.

## Verified looks right

- **`/heroes/` desktop:** stages compose cleanly and center well; the fixed left ledger rail (192px) does not overlap the stage crest (rail right=220, card left≈520). 5★ stages carry Apex Gold, 4★ rail entries carry fuchsia dots — rank accents correct. No horizontal overflow, no console errors.
- **`/heroes/` share modal (desktop + mobile 390):** composes as a production plaque stage — identity pill ("Are you @garrytan?"), the orbital medallion, and the compact icon control cluster (download / link / X / fullscreen) all fit at 390px without clipping. `ORIGIN` in the caption renders **gold**, not red (E4 correct). Rank reads "Ultimate · 5★" (E2 correct).
- **Profiles desktop (mattpocock, obra):** medallion + gold wreath present and well-sized; name/handle/stat hierarchy sane; Honor Red reserved for the contributor handle only; Back / View-all row clears the fixed nav (row top=96 vs nav bottom=60). Timeline panel readable. No horizontal overflow, no console errors. (Note: initial captures caught the "Skills are catalogued / Names are earned" intro splash mid-play — that is an intentional intro overlay, dismissible via click; settled page is clean.)
- **`/reports/` index:** "The ledger, week by week" header composes cleanly with generous nav clearance; Archive table (2026-28 row, Layer L3 tag) reads well. No overflow.
- **`/named/report.html` (no `?id`):** clean, intentional empty state ("No skill specified" + guidance + "Browse all named skills"); proper nav clearance and full footer. Reads as designed, not broken.
- **Mobile tables:** `/reports/2026-28/` "Trending this week" table fits at 390px (SKILL / LEVEL columns), no horizontal scroll on any surface tested.
- No `.wip-banner` present on any prestige surface (none required).
