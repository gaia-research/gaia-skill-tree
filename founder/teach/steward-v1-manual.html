Founder teaching file · Steward V1

Operate the maintenance governor—without granting it governance.

This is the manual interface for the shipped V1 control plane. Steward observes local repository conditions, records maintenance debt, repairs one narrow Class A mirror drift, prepares one bounded Class B packet, and compresses explicit Class C questions into a founder queue.

Authority rule. V1 never creates an issue or PR, runs an agent, executes a Class B packet, merges, releases, changes canonical registry state, assigns trust/rank, or decides a generic mapping. A packet and a queue are reports, not actions.

Before you run anything

  1. Use a disposable clone for any run exercise. It can repair only the bundled schema mirror, but it is still a mutation.
  2. Install the development dependencies and materialize the repository’s ignored Class-P test prerequisites.
  3. Use scan, dispatch, and founder freely: their durable state is confined to ignored .gaia/steward/.
python -m pip install -e ".[dev]"
python scripts/assemble_gaia.py
python scripts/generateNamedIndex.py
python -m pytest -q

The two generator commands are normal clean-checkout test setup. Their outputs are ignored Class-P artifacts; they do not change canonical source files.

The four commands

observe

Scan

Collect deterministic sensors, reconcile semantic debt, and write a small immutable receipt. A healthy result is useful: it says no_change.

gaia --registry "$PWD" steward scan --json
one Class A lane

Run

Attempt the sole authorized repair: bundled schema-mirror drift. It refuses unknown coverage, a dirty target, stale state, path escape, or failed proof.

gaia --registry "$PWD" steward run --json
report only

Dispatch

Render a policy-bounded Tree Keeper packet for one fresh Class B debt. It does not invoke a model, an agent, a command, or a worktree.

gaia --registry "$PWD" steward dispatch <debt-id> --json
founder decision

Founder

Render a deduplicated Class C decision queue. It groups only exact normalized decision targets and never chooses the mapping.

gaia --registry "$PWD" steward founder --json

Class C: inspect a real governance-shaped question

Most checkouts correctly produce an empty queue. To exercise the report-only queue without inventing canonical state, provide one explicit current, unresolved local candidate. This ignored file is an input to the report; it is not an intake, an issue, or a registry write.

mkdir -p .gaia/steward
cat > .gaia/steward/discovery-mapping-input.json <<'JSON'
{
  "schemaVersion": "steward-discovery-mapping-input-v1",
  "candidates": [
    {
      "candidateId": "proof/open-candidate",
      "sourceRepo": "owner/repository",
      "sourceState": "current",
      "disposition": "unresolved"
    }
  ]
}
JSON

gaia --registry "$PWD" steward founder --json
Input contract and failure behavior
  • schemaVersion must be exactly steward-discovery-mapping-input-v1.
  • Each candidate needs a safe ASCII slash-separated candidateId, a nonempty sourceRepo, sourceState: "current", and disposition: "unresolved".
  • The candidate ID is normalized before canonical lookup and grouping. If an equivalent canonical named mapping already exists, it is excluded.
  • Malformed explicit current/unresolved input fails closed: exit 2, no JSON report, no debt/receipt state change, and a coverage error on stderr.

What to inspect

  • Receipt: .gaia/steward/receipts/*.json is immutable. Equivalent repeat work reuses it.
  • Debt ledger: .gaia/steward/debt.json is local, deduplicated state—not canonical registry data.
  • Class A proof: a successful repair requires recursive parity and python scripts/sync_bundled_schemas.py --check.
  • Class B packet: read its paths, commands, proof, stop conditions, zero model budget, and escalation boundary before any later execution system is considered.
  • Class C queue: treat it as a ruling request. Make the governance decision outside Steward; V1 only presents it.

Stop immediately if a report shows unknown coverage, stale/resolved debt, an unsupported authority class, malformed controlled input, path/symlink protection failure, or failed proof. That is Steward behaving correctly.
